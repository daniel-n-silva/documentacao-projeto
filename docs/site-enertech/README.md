# Site de apresentação ThEndorSemenT — ENERTECH 2026

Página única para apresentar a ThEndorSemenT, os departamentos e os projetos incubados a possíveis investidores e parceiros na ENERTECH 2026 (Sabugal, 19 a 21 de novembro).

Conteúdo e imagens a partir da apresentação ThEndorSemenT / ENERTECH 2026. HTML e CSS simples, sem build nem dependências; as letras vêm do Google Fonts.

## Ver em local

```bash
cd docs/site-enertech
python3 -m http.server 8790
```

e abrir http://localhost:8790.

## Ficheiros

| Ficheiro | O quê |
|---|---|
| `index.html` | A página |
| `tokens.css` | Cores, letra, tamanhos e espaçamentos (um sítio só para mudar o visual) |
| `base.css` | Regras de base |
| `site.css` | Estilos das secções |
| `img/` | Selo, imagem dos departamentos, imagens e logótipos dos projetos, logótipo Smart Nexus |
